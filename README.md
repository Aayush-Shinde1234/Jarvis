# 🤖 JARVIS - Python Voice Assistant

A voice-controlled assistant built with Python.

## Features

* 🎤 Voice Recognition
* 🗣️ Text-to-Speech
* 🌐 Open Websites (Google, YouTube, ChatGPT, GitHub)
* 🔍 Google Search
* 🎵 Play YouTube Videos
* 💻 Open Apps (Chrome, VS Code, Notepad, Calculator)
* 📅 Date, Time & Day
* 😄 Jokes & Random Facts
* ⚙️ Shutdown & Sleep Commands

## Technologies

* Python
* SpeechRecognition
* pyttsx3
* pyjokes
* randfacts

## Run

```bash
python main.py
```

Say **"Jarvis"** to activate.
